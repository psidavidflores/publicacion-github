# Kit de Terapia del Lenguaje

Biblioteca digital estática preparada para GitHub Pages.

## Estructura

- `docs/`: sitio público, catálogo y configuración de la interfaz.
- `artes/`: piezas visuales del producto.
- `PUBLICAR.md`: procedimiento de publicación.
- `REVISION_DERECHOS.md`: control interno, fuera de `docs/`.

Los archivos originales permanecen fuera de esta publicación, en `recursos-originales/`. La página usa GitHub Releases para distribuir los materiales, porque el catálogo completo contiene archivos grandes.
